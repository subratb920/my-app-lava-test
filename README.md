# my-app-lava-test

Testing project creation from continuum lava

A Vite project created with Continuum.

## Getting started

```sh
npm install
npm run dev
```

Copy `.env.example` to `.env` and fill in the values.

- `npm run build` builds for production into `dist/`.

Requires Node.js 22.22 or newer.

## Dependencies

- **React Router**: Pages and links in the browser (declarative routing). ([docs](https://reactrouter.com/))
- **Redux Toolkit**: A predictable global store, with React Redux bindings. ([docs](https://redux-toolkit.js.org/))
- **Axios**: HTTP client with a ready API client using the API_URL setting. ([docs](https://axios-http.com/))
- **Tailwind CSS**: Utility-first CSS, wired into Vite. ([docs](https://tailwindcss.com/docs))
- **React Hook Form**: Performant forms with easy validation. ([docs](https://react-hook-form.com/))
